Overview: What is Pipeline 2?

Pipeline 2 is an image-based approach to computing scagnostics (scatterplot diagnostics) that uses continuous/subpixel geometry rather than discrete pixel operations.

Key Idea: Instead of working directly with pixels, we convert the scatterplot to a continuous density field, then extract geometric features (contours, skeletons) at subpixel precision. This produces more stable and accurate metrics that better match the original graph-theoretic scagnostics.

Pipeline Flow

Raw Points → KDE Density Grid → Gaussian Blur → Multi-Threshold → Marching Squares → Skeleton + DT → 9 Metrics

Why Pipeline 2 over Pipeline 1?

Pipeline 1 (Morphological)
  • Works on binary pixel grids
  • Uses morphological operations (erosion, dilation)
  • Discrete pixel counting
  • Can have quantization artifacts
Pipeline 2 (Continuous)
  • Works on continuous density fields
  • Uses marching squares for subpixel contours
  • Continuous area/perimeter via calculus
  • More stable and accurate

1 Input & Smoothing

This step converts raw points to a continuous density field using Kernel Density Estimation (KDE), then applies Gaussian blur to stabilize the field for subsequent operations.

Step 1a: KDE Density Estimation

Each point contributes a Gaussian "splash" to the density grid. Points that are close together create higher density regions.

density(x, y) = Σ exp(-((x - pᵢ)² + (y - pᵢ)²) / (2σ²)) where: - (pᵢ) are the input points - σ = bandwidth (default 3.0 pixels)

Step 1b: Gaussian Blur

A separable Gaussian blur smooths the density field, reducing noise and making contour extraction more stable. The blur is applied in two passes (horizontal, then vertical) for efficiency.

G(x) = (1 / σ√(2π)) * exp(-x² / (2σ²)) Kernel size = ceil(3 * σ) * 2 + 1
Why blur? Without smoothing, the density field can have sharp discontinuities that cause unstable contour extraction. The blur parameter σ (default 1.0) controls how much smoothing is applied.

2 Multi-Threshold Segmentation

This step creates multiple binary masks at different density thresholds, emulating the family of α-shapes from the original scagnostics paper.

Why Multiple Thresholds?

In the original scagnostics, α-shapes at different α values capture different aspects of the point distribution. Lower thresholds capture the full extent, while higher thresholds capture only the dense core.

Percentile What It Captures Analogous To
P50 (50th) Outer extent, includes sparse regions Large α (loose hull)
P75 (75th) Main body of the distribution Medium α (balanced)
P90 (90th) Dense regions only Small α (tight fit)
P95 (95th) Core clusters / peaks Very small α

Threshold Computation

1. Collect all non-zero density values from the grid 2. Sort values in ascending order 3. For percentile P: threshold = values[floor(P/100 * count)] 4. Binary mask: pixel = 1 if density >= threshold, else 0

3 Subpixel Contour Extraction

This is the core innovation of Pipeline 2. Instead of counting pixels, we extract subpixel-accurate contours using the Marching Squares algorithm.

Marching Squares Algorithm

Marching Squares examines each 2x2 cell of the grid and determines how the contour passes through it based on which corners are above/below the threshold.

For each 2x2 cell with corners (a, b, c, d): a---b Case is determined by which corners | | are above threshold (16 possible cases) c---d Contour position is interpolated linearly: t = (threshold - v0) / (v1 - v0) point = p0 + t * (p1 - p0)

Convex Hull (Graham Scan)

The convex hull is the smallest convex polygon containing all contour points. We compute it using the Graham Scan algorithm.

1. Find lowest point (anchor) 2. Sort other points by polar angle from anchor 3. Process points, keeping only left turns: - For each point P: - While last two points and P make a right turn: - Remove the middle point - Add P to hull

Continuous Area (Shoelace Formula)

Unlike pixel counting, we compute the exact area enclosed by the contour polygon.

Area = ½ |Σᵢ (xᵢ * yᵢ₊₁ - xᵢ₊₁ * yᵢ)| This is exact for any polygon, regardless of grid resolution.

Continuous Perimeter

Perimeter = Σᵢ √((xᵢ₊₁ - xᵢ)² + (yᵢ₊₁ - yᵢ)²)

4 Distance Transform & Skeleton

The skeleton (medial axis) is extracted using the Zhang-Suen thinning algorithm, which iteratively removes boundary pixels while preserving topology.

Euclidean Distance Transform (EDT)

The EDT computes, for each pixel inside the shape, its distance to the nearest boundary.

DT(x, y) = min distance to any background pixel Computed efficiently using two-pass algorithm: Pass 1 (forward): scan top-to-bottom, left-to-right Pass 2 (backward): scan bottom-to-top, right-to-left

Zhang-Suen Thinning

This algorithm extracts a 1-pixel-wide skeleton that preserves the shape's topology.

Repeat until no changes: Sub-iteration 1: Remove pixels satisfying conditions A Sub-iteration 2: Remove pixels satisfying conditions B Conditions check: - Number of neighbors (2-6) - Number of 0-1 transitions around pixel - Specific neighbor patterns

Skeleton Features

  • Endpoints: Skeleton pixels with exactly 1 neighbor (green circles)
  • Junctions: Skeleton pixels with 3+ neighbors (red diamonds)
  • Branches: Paths between endpoints/junctions
Why skeleton? The skeleton captures the "shape" of the distribution. A long, thin skeleton indicates stringy data. Many junctions indicate complex, branching structure.

5 Final Scagnostics Metrics

The final step computes all 9 scagnostics metrics using the geometric features extracted in previous steps.

Reference: These metrics are based on Wilkinson et al. (2005) "Graph-Theoretic Scagnostics" but adapted for image-based computation.

All 9 Scagnostics Metrics Explained

Stringy Shape

Measures how chain-like or linear the data distribution is. High stringy means the points form a thin, elongated path with few branches.

stringy = skeleton_length / (skeleton_length + n_junctions * k) where k = 5 (junction penalty factor) Alternative: (endpoints - 1) / max(1, junctions) High when: few junctions, long skeleton

Sparse Density

Measures how scattered or spread out the points are. High sparsity means points don't fill much of the available space.

sparse = 1 - (filled_area / hull_area) filled_area = continuous area from contour hull_area = area of convex hull High when: points are scattered, low fill ratio

Convex Shape

Measures how well the shape fills its convex hull. A circle has convexity ~1, while a star shape has low convexity.

convex = contour_area / hull_area contour_area = area inside the extracted contour hull_area = area of the convex hull High when: shape is blob-like, no concavities

Skinny Shape

Measures elongation using the isoperimetric quotient. A circle has skinny = 0, while an elongated ellipse has high skinny.

skinny = 1 - (4π * area) / perimeter² This is 1 minus the "circularity" or "roundness" A circle: 4πA/P² = 1, so skinny = 0 A line: 4πA/P² → 0, so skinny → 1

Clumpy Clustering

Detects presence of multiple clusters. High clumpy means the data has distinct groupings rather than a single continuous distribution.

clumpy = 1 - (n_components_high / n_components_low) n_components_high = connected components at P95 n_components_low = connected components at P50 High when: high threshold splits into more pieces

Outlying Outliers

Measures presence of points far from the main distribution. Based on how much the convex hull extends beyond the core.

outlying = 1 - (core_area / hull_area) core_area = area at high threshold (P90) hull_area = convex hull of all points High when: hull much larger than dense core

Skewed Distribution

Measures asymmetry in the distance transform distribution. High skew indicates the shape has varying thickness.

skewed = (mean_DT - median_DT) / max_DT DT = distance transform values inside shape High when: shape has uneven thickness (thick parts pull mean above median)

Striated Orientation

Measures orientation coherence using the structure tensor. High striated means gradients in the density field are aligned (parallel lines).

Structure tensor: T = [ΣIx², ΣIxIy] [ΣIxIy, ΣIy²] Coherence = (λ1 - λ2)² / (λ1 + λ2)² where λ1, λ2 are eigenvalues of T High when: strong directional gradient pattern

Monotonic Trend

Measures linear trend using correlation of row centroids. High monotonic means there's a consistent increasing or decreasing pattern.

For each row y, compute centroid: centroid_x[y] = Σ(x * density[y,x]) / Σdensity[y,x] monotonic = |correlation(y, centroid_x)| High when: centroids move consistently left/right as you go up/down (linear relationship)

Summary: Metric Categories

Category Metrics What They Measure
Shape Stringy, Convex, Skinny Geometric properties of the distribution boundary
Density Sparse How spread out points are within their extent
Clustering Clumpy Presence of multiple distinct groups
Outliers Outlying Points far from the main distribution
Distribution Skewed Asymmetry in shape thickness
Orientation Striated Directional coherence / parallel structure
Trend Monotonic Consistent increasing/decreasing pattern
